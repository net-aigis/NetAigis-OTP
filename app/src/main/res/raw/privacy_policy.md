## General Information

This Privacy Policy explains how personal data is handled when using this app.

The app is designed as a local OTP authenticator. Token data is stored locally on the user's device. The provider does not operate a server backend for this app and does not automatically receive token data from the app.

## Data Processed in the App

Depending on how the user uses the app, the following data may be entered and stored locally:

Token metadata such as issuer, account name, alias, category, algorithm, digits, interval or counter, and icons.
OTP secrets required to generate one-time passwords.
Import, export, and backup data needed to operate app functions.
Optional settings such as authentication preferences and clipboard behavior.

## Purpose of Processing

The data is processed to provide the app functions selected by the user, in particular:

Storing and displaying OTP tokens.
Generating one-time passwords.
Organizing tokens by category.
Creating exports and restoring imports.
Protecting app access with device authentication when enabled.

## Local Storage

The app stores data locally on the user's device in an app database.

The provider has no access to this locally stored data unless the user actively exports, transfers, sends, or otherwise submits the data to the provider or a third party.

## Camera Permission

If the user scans a QR code, the app requests camera access only to read otpauth provisioning data. Camera frames are processed on-device and are not uploaded to the provider.

## No Automatic Tracking

The app does not perform automatic location tracking.
The app does not automatically transmit token data to the provider.

## Export and Backup

The app may allow users to export or import their token data. The user decides where exported files are stored or with whom they are shared.

Users are responsible for protecting exported files against unauthorized access, loss, or misuse. Exported files may contain OTP secrets.

## Permissions and Storage Access

If the app requests access to files or folders, this is used for user-selected import or export functions.

The app does not request broad all-files storage access.

## Data Sharing

The provider does not sell user data.
The provider does not share locally stored app data with third parties because the provider does not have access to such data by default.
Data may be shared only if the user actively exports, transfers, sends, or submits it.

## Support Requests

If the user contacts support by e-mail or another communication channel, the information provided by the user will be processed to handle the request.

This may include the user's e-mail address, message content, attachments, technical information voluntarily provided by the user, and any exported app data the user chooses to send.

## Retention

Data stored inside the app remains on the user's device until the user deletes it, clears the app data, or uninstalls the app.

Support communication is retained only as long as necessary to handle the request and comply with applicable legal or business obligations.

## User Responsibility

Users are responsible for the correctness of the data entered into the app.
Users are responsible for creating and securely storing backups and exports if they need to preserve their tokens.
Users are responsible for protecting their device, exported files, and OTP secrets against unauthorized access.
