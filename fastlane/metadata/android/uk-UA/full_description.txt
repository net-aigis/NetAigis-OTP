NetAigis OTP додає другий рівень захисту для ваших облікових записів в інтернеті.
Додаток створює на пристрої одноразові паролі (OTP), які використовуються разом зі звичайним паролем.
Коди працюють без підключення до інтернету, зокрема в режимі польоту.

Додавайте токени, скануючи QR-код або вводячи конфігурацію вручну.
NetAigis OTP реалізує відкриті стандарти TOTP (RFC 6238) і HOTP (RFC 4226), тому працює з Google, GitHub, Nextcloud, Forgejo та багатьма іншими службами.

На відміну від FreeOTP+, NetAigis OTP допомагає зрозуміліше впорядковувати токени:
<ul>
    <li><b>Псевдонім</b> — необов’язкова назва у списку замість видавця; не впливає на обчислення OTP і враховується під час пошуку</li>
    <li><b>Піктограма</b> — необов’язкова вбудована піктограма, що використовується, якщо власне зображення токена не задано</li>
    <li><b>Категорії</b> — необов’язкові групи (наприклад, Робота або Особисте) з фільтрами списку (Усі / Жодної / за категорією)</li>
    <li>Вибір мініатюри без власного зображення: Піктограма → Псевдонім → Видавець</li>
</ul>

<b>Інші функції:</b>
<ul>
    <li>Сканування QR-кодів за допомогою CameraX</li>
    <li>Експорт та імпорт токенів (JSON / URI ключа) через Storage Access Framework</li>
    <li>Дизайн Material із підтримкою темної теми</li>
    <li>Пошук токенів</li>
    <li>Відомості про токен і редагування з довідкою до полів</li>
    <li>Необов’язкове блокування додатка біометрією / PIN-кодом</li>
    <li>Офлайн-піктограми видавців для багатьох відомих служб</li>
</ul>

NetAigis OTP створено на основі форка FreeOTP+; додаток підтримує <a href="https://net-aigis.de/">NetAigis</a>.
