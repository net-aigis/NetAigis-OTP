NetAigis OTP 为您的在线账户增加第二层安全保护。
应用在设备上生成一次性密码（OTP），与常规密码一起使用。
验证码可离线使用，包括飞行模式。

可通过扫描二维码或手动输入配置来添加令牌。
NetAigis OTP 实现开放标准 TOTP（RFC 6238）与 HOTP（RFC 4226），可与 Google、GitHub、Nextcloud、Forgejo 等众多服务配合使用。

<b>功能：</b>
<ul>
<li>使用 CameraX 扫描二维码</li>
<li>通过 Storage Access Framework 导入/导出令牌（JSON / key URI）</li>
<li>支持深色主题的 Material Design</li>
<li>搜索令牌</li>
<li>令牌详情与编辑</li>
<li>可选的生物识别 / PIN 启动锁定</li>
<li>面向众多知名服务的离线发行方图标</li>
</ul>

NetAigis OTP 基于 FreeOTP+ 分支，由 <a href="https://net-aigis.de/">NetAigis</a> 维护。
