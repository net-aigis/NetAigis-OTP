NetAigis OTP lägger till ett andra säkerhetslager för dina onlinekonton.
Appen genererar engångslösenord (OTP) på enheten som används tillsammans med ditt vanliga lösenord.
Koderna fungerar offline, även i flygplansläge.

Lägg till token genom att skanna en QR-kod eller ange konfigurationen manuellt.
NetAigis OTP implementerar öppna standarderna TOTP (RFC 6238) och HOTP (RFC 4226) och fungerar med Google, GitHub, Nextcloud, Forgejo och många andra tjänster.

<b>Funktioner:</b>
<ul>
<li>Skanna QR-koder med CameraX</li>
<li>Exportera och importera token (JSON / key URI) via Storage Access Framework</li>
<li>Material Design med mörkt tema</li>
<li>Sök token</li>
<li>Tokendetaljer och redigering</li>
<li>Valfritt biometriskt / PIN-lås vid start</li>
<li>Offline-ikoner för många kända tjänster</li>
</ul>

NetAigis OTP bygger på en FreeOTP+-fork och underhålls av <a href="https://net-aigis.de/">NetAigis</a>.
